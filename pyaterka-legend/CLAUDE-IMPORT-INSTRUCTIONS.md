# Инструкция для Claude: каталог игроков HLTV

Используй файлы этого каталога как исходный справочник для переработки карточек в «Пятёрке Легенд»:

- `HLTV-PLAYERS-CATALOG.json` — структурированные записи игроков, команд, страны, URL фотографии и HLTV-профиля.
- `HLTV-PLAYERS-CATALOG.html` — визуальная проверка аватарок и сопоставления игрок → команда → страна.
- Исходная база: `data.js`.

## Важно при импорте

1. Не считать отсутствие поля подтверждением того, что у игрока нет страны или фотографии. Пустые поля означают, что значение не было подтверждено в исходной базе.
2. Не подставлять чужие аватарки и не сопоставлять фотографии только по похожему нику. Если профиль не подтверждён — оставлять явный placeholder до ручной проверки.
3. Использовать `profileUrl` и `profileId` для сверки игрока на HLTV. Изображение из `photo` использовать только вместе с соответствующей записью.
4. Сохранять оригинальные никнеймы, включая регистр, цифры и спецсимволы.
5. Команду брать из поля `team`; страну — из `country` и `countryCode`. В интерфейсе игры показывать флаг без текстового названия страны.
6. Этот экспорт содержит текущие записи существующей базы игры. Перед заявлением о полной актуальности ростеров проверь изменения на HLTV; не выдумывай недостающие данные.
7. Не менять `main`. Работай только в текущей feature-ветке и сохрани совместимость ID уже выпущенных карточек/пользовательских коллекций.
8. После импорта проверь, что каждый ID уникален, фотографии соответствуют никам, команды и флаги не перепутаны, а карточки без подтверждённых данных корректно отображаются.

## Состав экспорта

Снимок базы от 11 ноября 2026 года: 654 записи игроков, 131 командная запись. В экспорте 389 URL фотографий, 358 кодов стран и 393 записи с HLTV-источником. Эти числа не означают, что все остальные игроки не существуют: для части записей исходная база не содержит подтверждённых метаданных.
