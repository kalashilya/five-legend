# CHANGELOG — «Пятёрка Легенд»

## 2026-11-12 — Inferno, Ancient и Anubis по настоящим радарам CS2 (ветка `dev`)
- Изменено: три карты, которые были упрощёнными схемами, сделаны по настоящим радарам CS2. Источник — радары из открытого проекта boltobserv, сами картинки в игру не попадают.
  - Проходимые зоны сняты с радара автоматически, это 110–158 зон на карту: улицы, площади, коридоры, тупики.
  - Ящики на точках и в проходах тоже сняты с радара.
  - Узлы и маршруты расставлены вручную по колаутам:
    - Inferno — банан, машина, стройка, арка, мид, шорт, апартаменты, бойлер, балкон, яма, библиотека;
    - Ancient — A-мейн, донат, мид, пещера, B-мейн, рампа, лонг B, локоть;
    - Anubis — B-мейн, лонг B, двери B, каналы, мид, коннектор, A-мейн, под A.
  - Как на Mirage и Dust II, у каждой из трёх карт:
    - свои расстановки защиты для каждой точки;
    - свои маршруты атаки (выход, сплит, люркер);
    - места после закладки;
    - гранаты выхода и стартовая граната на миде.
- Движок радара: для карт, снятых с радара, запас до стены считается до границы всей проходимой области, а не каждой полосы. Когда прямого прохода нет, путь между узлами ищется по сетке (A*). В 3D под такими картами один общий пол вместо сотни плит. Mirage и Dust II считаются как раньше.
- Проверено по 25 матчей на каждой карте: убийств без видимости 0, сквозь стену 0, на слишком большой дистанции 0. Длительность раунда и доли исходов — как на Mirage и Dust II.
- Инструменты сборки карт: `pyaterka-legend/tools/maps/`, порядок — в README.
- Файлы: pyaterka-legend/radar-maps.js (новый), pyaterka-legend/radar.js, pyaterka-legend/live3d.js, pyaterka-legend/build.sh, pyaterka-legend/tools/maps/*, pyaterka-legend/pyaterka-legend-offline.html, .gitignore, CHANGELOG.md, PROJECT_STATE.md.
