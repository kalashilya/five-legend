# Пятёрка Легенд

## Играть
**[Открыть последнюю версию игры](pyaterka-legend/pyaterka-legend-offline.html)**

Готовая браузерная версия: HTML-файл можно открыть напрямую, без установки и сервера. Для веб-публикации используйте корневой `index.html` (если GitHub Pages включён для репозитория).

## Проект
Основная игра находится в `pyaterka-legend/`:
- `pyaterka-legend-offline.html` — собранная автономная версия игры.
- `head.html`, `core.js`, `meta.js`, `ui.js` — исходники интерфейса и логики.
- `data.js` — сгенерированная база карточек.
- `teams.txt` — список команд.
- `hltv-data.json` — снимок данных HLTV.
- `ids.json` — постоянный реестр ID карточек.
- `gen.js` — генератор базы.
- `build.sh` — сборка автономного HTML.

### Сборка и проверки
Из каталога `pyaterka-legend`:
```bash
node gen.js
bash build.sh
node test.js
```
После изменения исходников или базы необходимо пересобрать `pyaterka-legend-offline.html`.
