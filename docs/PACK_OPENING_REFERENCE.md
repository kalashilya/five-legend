# Открытие паков: разбор референса и план для «Пятёрки Легенд»

Референс: запись экрана мобильной игры про футбольные карточки (44 секунды), присланная 11.11.2026.
Мы берём из неё ритм и приёмы, а не графику: логотипы, карточки, флаги клубов и интерфейс референса не копируются.

## Что происходит в референсе

| Время | Экран | Приём |
|---|---|---|
| 0–5 с | Ежедневная награда | Два варианта награды, ряд «7 дней подряд», после выбора — «Награда сохранена» |
| 6–15 с | Главная | Три страницы плиток, листаются вбок. Крупный баннер с вырезанным фото игрока, плитки с карточками, торчащими за край |
| 16–23 с | Магазин паков | Вкладки «Паки дня / Мои паки / Жетоны». Строка пака: название, описание, таймер, цена, обложка справа. Нажатие раскрывает «− Открыть 1 +» |
| 23–24 с | Пак на весь экран | Обложка пака в центре, тёмный фон, лёгкое свечение |
| 24,5–25,5 с | Разлом | Тонкие золотые трещины по всему экрану, пак гаснет, разлетаются чёрные и золотые осколки |
| 26 с | Рубашка карточки | Пустая золотая карточка: уже видно, что выпала «золотая». Фон — лучи и зеркальный пол из треугольников |
| 27–29 с | Шаг 1: страна | Сверху флаг страны, пол окрашивается в её цвета, треугольники пола переливаются |
| 30–32 с | Шаг 2: клуб | Сверху эмблема клуба, пол меняет цвет, эмблема появляется на рубашке |
| 33–34 с | Шаг 3: позиция | Неоновые стрелки «► CM ◄», надпись позиции встаёт на карточку |
| 35 с | Раскрытие | Неоновая полоса, вокруг карточки растёт светящаяся рамка, карточка заполняется фото и цифрами, вспышка треугольных частиц, метка NEW |
| 36–41 с | Показ | Карточка стоит на фоне лучей, отражается в полу |
| 42–44 с | Итог | Карточка рассыпается мозаикой, все карточки пака собираются в сетку, кнопка «Сохранить» |

Почему это работает:
1. Редкость видна сразу по цвету рубашки, а игрока раскрывают по одной подсказке. Каждая подсказка сужает круг и держит интригу.
2. Каждый шаг меняет цвет пола и фона: экран живой, хотя карточка стоит на месте.
3. Зеркальный пол и лучи дают глубину без тяжёлой 3D-сцены.
4. Полная церемония только для главной карточки, остальные сразу ложатся в сетку.
5. Кнопка пропуска «»» в углу на каждом шаге.

## Как перенести в CS2

| Шаг референса | У нас |
|---|---|
| Обложка пака | Обложка кейса нашего типа (Базовый, Про, Элитный) на весь экран |
| Разлом | Защёлки кейса отщёлкиваются, крышка трескается лазерными линиями цвета кейса, осколки |
| Рубашка карточки | Рубашка в цвете редкости: Ширпотреб, Армейское, Запрещённое, Засекреченное, Тайное; особые версии — своя рубашка |
| Страна | Код и название страны из `hltv-data.json` (есть у 394 игроков). Свои простые плашки цветов страны, без чужой графики |
| Клуб | Название команды и её цвет (уже есть в карточке как `--tc`). Без логотипов команд |
| Позиция | Роль: AWP, ENTRY, SUP, LURK, IGL — неоновые стрелки «► AWP ◄» |
| Раскрытие | Рамка редкости, фото, OVR и шесть показателей, метка «новая» или «дубль» |
| Пол | CSS-пол из треугольников в перспективе с отражением, окрашивается под шаг |
| Итог | Сетка из 5 карточек, кнопки «Забрать» и «Продать дубликаты» |

Церемония занимает 8–10 секунд, обычное раскрытие — около 3 секунд. Это совпадает с пунктами 8.2–8.3 ТЗ.
Голографический сканер из ТЗ превращается в стиль подсказок: линии сканирования и шумы при смене шага.

## Порядок работ

1. Экран открытия: обложка → разлом → рубашка → три подсказки → раскрытие → сетка. Пропуск шага и всей церемонии.
2. Пол из треугольников и лучи (CSS), окраска по шагам.
3. Рубашки пяти редкостей и особых версий.
4. Магазин в виде строк с раскрытием «− Открыть N +».
5. Позже: главная с крупными плитками-баннерами и ряд ежедневных наград за 7 дней (календарь серии входов есть в нерешённых вопросах ТЗ, № 13).
