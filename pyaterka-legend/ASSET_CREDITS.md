# Third-party asset credits

## Tactical operator used in the case reveal

The case reveal loads the rigged soldier model from the public repository
[cktang88/3d-fps](https://github.com/cktang88/3d-fps), file
[public/assets/models/characters/soldier.glb](https://github.com/cktang88/3d-fps/blob/main/public/assets/models/characters/soldier.glb).

- Character model: **“FREE [Military Soldier] RIGGED” by BAMEN**, licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.
- Original model source: https://sketchfab.com/3d-models/free-military-soldier-rigged-e9c56308a67d4a3db62e914fafa4d198
- Animation clips: Quaternius Universal Animation Library 1 & 2 (CC0); selected mocap clips from the 100STYLE dataset by Ian Mason, Sebastian Starke and Taku Komura (CC BY 4.0), as credited by the upstream repository.
- 100STYLE source: https://zenodo.org/records/8127870
- Quaternius source: https://quaternius.com

The model is currently loaded from the upstream raw GitHub URL at runtime; it is not vendored into this repository. An internet connection is therefore required for this 3D reveal. If the upstream asset becomes unavailable, the existing procedural fallback is used.

This project does not claim ownership of the third-party model or animation assets. The CC BY 4.0 material must remain attributed when redistributed.
